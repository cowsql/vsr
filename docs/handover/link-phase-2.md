## Decisions (docs/io-design.md section 10)
- 72: link sockets are raw until takeover into an engine slot via `update_file` (`vsr_io_engine_install`); plain multishot ACCEPT; EXTERNAL exchanges the preamble on the raw fd before the HANDSHAKE op; listener state in a fixed table (`VSR_IO_LISTENERS_MAX` 8).
- 73: authorize needs a known node; identical re-authorize still wants a link; revoke closes links only when nothing names the node; node_clear removes authorizations; unknown inbound identities refused; own node never dialed; want set only while unlinked, cleared at establish/idle close; any failed outbound step backs off; unidentified inbound failures are nobody's.
- 74: `vsr_io_links_deadline` dispatch, the module consumes its own slots, `io->now` is the completion-time clock.
- 75 (placeholder number): MESSAGE refusals DROP the frame and count `frames_rejected` while the link stays up: envelope shorter than 56 bytes, cluster without a replica on this engine, `from` not authorized for the link's node (`vsr_io_links_lookup(cluster, from) != link->node`, decision 67), or a body the replica's decoder rejects (the engine counts that one). A MESSAGE before the handshake or on a STREAM link closes the link with -EPROTO. Only an accepted frame updates `node->last_received_ns`.
- 76 (placeholder): receive runs: the PARTIAL run plus up to `VSR_IO_LINK_HELD` (8) HELD runs in arrival order, one pool reference each. A straddling frame is copied into a reassembly slab (`vsr_io_pool_acquire(&io->pool, false)`) up to the frame's end only (header first), the slab released once the frame is consumed. No free slab, or a MESSAGE without a free region: `link->retry` set, `links.retries_due` counted, every `vsr_io_links_poll` calls `link_drain`. A ninth held run closes the link with -ENOBUFS. Closing releases every run.

## Implemented in phase 2 (src/io/link.c, receive section)
- `link_received(slab, bytes)`: `vsr_io_pool_recv_begin`, then: partial empty -> becomes the partial; contiguous with the partial (no held runs) or with the last held run -> merged, the delivery's reference dropped; else appended to `held[]`; full -> -ENOBUFS close. Then `link_drain`.
- `link_drain`: loops `link_carve` (returns CARVE_EMPTY / INCOMPLETE / BLOCKED / CLOSED). EMPTY with held runs -> the first held run becomes the partial. INCOMPLETE with a held run -> `link_reassemble` (acquire the reassembly slab once, copy the partial into it at offset 0, then copy `link_frame_missing` bytes from held[0], popping it when emptied). BLOCKED or no reassembly slab -> `retry`. `links.reassembled` counts frames copied (tests use it).
- `link_carve`: unchanged framing (preamble, header via `vsr_io_codec_get_frame` with limit `frame_limit - 24`, body CRC) but `link_frame` now returns false when the frame cannot be consumed (MESSAGE without a region) -> CARVE_BLOCKED without consuming. When the run empties its reference is released and `reassembly_slab` cleared if it was that slab.
- `link_message`: `link_envelope` reads cluster hi/lo, skips epoch/view, reads `from`; `vsr_io_engine_replica`; authorization; `vsr_io_engine_deliver(io, replica, body, link->partial_slab)` (the lease takes its own reference); `last_received_ns`.
- `link_release_partial` (called by `link_close`): releases the partial (its reference IS the reassembly slab's once the run lives there), a reassembly slab not yet holding the partial (cannot happen today), every held run; clears `retry`.
- `vsr_io_links_poll`: after dials and handshakes, `if (links->retries_due > 0)` drains every link with `retry`.
- Invariants: `partial_length == 0` implies `partial_slab == NONE` and `held_count == 0` (asserted in `link_received`); `reassembly_slab != NONE` implies `partial_slab == reassembly_slab` and `partial_offset == 0`; every run holds exactly one reference; a frame is decoded only when header and body are within the partial run; `frame_limit <= slab_bytes` makes the copy fit (asserted).

## Send side for phase 3 (already there from phase 1)
`link_write_control` / `link_write_hello` write into the send slab ring (`header_head/tail/sent`); `link_prepare_send` builds one send from `vecs` and applies the decision-38 flag rule (`link_send_flags`: all vectors in the pool -> ZERO_COPY | VECTORED | FIXED_BUFFER; else zero-copy without FIXED_BUFFER at or above `zero_copy_bytes`, plain below); `sends[VSR_IO_LINK_SENDS]` entries track begin/end stream offsets, header ring ranges, `zero_copy`/`fixed`; `link_send_complete` handles the result CQE, short sends (re-issue from the vectors), NOTIFs (`notified_offset`, `link_send_floor` advances the header ring floor), and `link_send_release`. Queue: `node->queue_head/queue_count` over `links->queue` (`link_queue` per node), `struct vsr_io_queued_send` {op, replica, message, length, crc, end}; `link->encoder/encoding` for a message continuing across sends. `vsr_io_links_send` must digest (`vsr_io_codec_message_digest`), resolve the member to a node through the authorizations, queue or RETRY; the carrier drains the queue at prepare; completions are queued as COMPLETE events into the replica's `completions` ring (see engine.h). Idle timeout already keeps the carrier while `queue_count > 0`.

## Open questions
Phase 1's: `options.nodelay` not applied; `link->peer` zero for accepted links; `io->now` at completion time lags one iteration; an accepted-descriptor flood beyond the 16-entry orphan table leaks; the HELLO waits when the pool is dry. Phase 2's: `VSR_IO_LINK_HELD` (8) is a judgement call (memory 96 bytes per link); a link retried at every poll while its replica has no region is a bounded busy retry (O(links) per poll); the reassembly slab is taken with internal priority so it may dip into the reserve; a stream link's frames are still dropped (phase 3).

## What engine part 2 must call, in order (unchanged from phase 1)
1. `vsr_io_complete`: `vsr_io_slots_resolve`, then for kinds LISTEN, CONNECT, RECV, SEND, SHUTDOWN call `vsr_io_links_complete(io, slot_index, cqe)`; run `check_closed` after.
2. `vsr_io_poll`: set `io->now`; drain `vsr_io_deadlines_pop` dispatching LINK and DIAL to `vsr_io_links_deadline(io, kind, index, now)`; then `vsr_io_links_poll(io, now)` (which now also retries held bytes, so it must run after lease releases of the previous iteration); drain the forwarded ring; route core SEND to `vsr_io_links_send` and queue COMPLETE(RETRY) when it returns `VSR_IO_RETRY`.
3. `vsr_io_submit`: COMPLETE of a HANDSHAKE op -> `vsr_io_links_handshake_done`.
4. `vsr_io_prepare`: pool provision first, then `vsr_io_links_prepare(io, sqes, capacity, &count)` (capacity >= 4), then the earliest deadline.
5. Public calls map 1:1: `vsr_io_node_set/clear/authorize/node_status`, `vsr_io_adopt`, `vsr_io_close` -> `vsr_io_links_shutdown`; `vsr_io_engine_install` is the engine helper; `vsr_io_engine_replica` and `vsr_io_engine_deliver` are what MESSAGE delivery uses.
