## What phase 3 must know about index_apply and replay
- `index_apply(store, offset, length, bytes, &status)` is static in the "Index application" section: `record_changes()` validates the header (get_record with limit = length, kind RECORD, header.length == length) and every descriptor (offset >= 48 + 24*count, offset + length <= length); then `apply_change` per descriptor from a cursor over its payload. Call it with the slab bytes of each valid record and its file offset. CORRUPT = bad bytes or a change contradicting the log (APPEND not at log_end, TRUNCATE below log_begin, IDENTITY after sequence 1); FAILED = op ring, versions or client table full.
- Before replay set `log_begin`, `log_end`, `retained_begin` (= log_begin; the ring is then [retained_begin, log_end)), `client_base`, `identity`/`identity_set`, `hard`, `anchor` from the start header. `log_start()` initialises an empty log (both 0) from the first APPEND/TRIM/RESTORE (the core's genesis is op 1), so a recovered log that starts at 0/0 is fine too. IDENTITY at sequence 1 sets superblock_dirty (harmless; the recovery superblock rewrite covers it).
- HARD_STATE/PUBLISH/RESTORE decode into `state_region` (hard's epoch in the first `epoch_bytes`, the anchor after; `state_regions()`); the manifest bytes are copied out of the record. segment_open encodes identity+hard only when `identity_set && hard.epoch != NULL` (a header packed between IDENTITY and HARD_STATE carries no state).
- PUBLISH/RESTORE during replay: `base_state` is NONE, so PUBLISH of an id that is not `last_capture` leaves the base alone and RESTORE empties the client table (clients_sweep(keep_none)), sets client_base = the RESTORE's sequence and client_base_id, then `retained_rebuild()`. CLIENTS records after it fill `current` again. After the scan load `clients-<anchor>` with base_begin / base_record / base_end(id, client_base): with no transaction waiting base_end applies the merge at once (`base_apply(BASE_FROM_FILE)`: entries the file does not cover pull client_base below their record). Then walk retained: `retained_rebuild()` is static; call it (or apply an empty RESTORE) — expose it if needed. Set `store->base_slot` if the file stays open for CLIENT loads (else -1: such loads complete FAILED).
- `reindexed`/`restored` are set by replayed TRUNCATE/TRIM/RESTORE; leave them (loads at older sequences RETRY, which is right after recovery).
- Freed slots at recovery: mark stale slots FREE (number 0, phase FREE); FREEING is a runtime-only state (waits for superblock_dirty == 0 at a superblock completion).

## Data structures added (struct vsr_io_store; store.c sections: Layout; Completions and queues; Ring and extents; Segments; Superblock; Client table; Op ring, versions, trim history; Logical state and client base; Index application; Packing; SYNC; Writes; Executor records; Loads; Open/poll/prepare/complete; Status/close; RECLAIM and freeing; Admission, captures, base files)
- Client table: `clients[clients_capacity]` open addressing, `client_home()` hash, backward-shift `client_delete()` (no tombstones; VSR_IO_CLIENT_TOMBSTONE unused), `client_prune()` deletes an entry with no record, no retained entry, not in flight; `clients_sweep(keep)`. Entry fields: current (number 0 = none; sequence 0 = only the base file has it, offset = file offset), base_offset (UINT64_MAX uncovered), capture_offset (reset by snapshot_clients), next_offset (base_begin..base_end), retained, inflight.
- Op ring: `op_slot(op)`, `op_current(op)` (NULL unless ops[op%n].op == op). APPEND fills {op, sequence, offset, length, change, index, client, previous = client's retained}. Versions: unsorted, swap-delete; `version_at(op, s)`. Trims: ring of VSR_IO_TRIM_HISTORY (sequence, log_begin); `trims_record` merges into the newest when full; `trims_reclaim(oldest)` pops events <= oldest, clears the ring below the new retained_begin.
- Loads: `loads` FIFO [operations] of vsr_io_pending_load {op, read, state QUEUED/READING/READ, count, slab, slot, base, offset, length, got}; `load_refs[operations*batch_entries]` (offset, sequence, length, change, index) resolved at accept time (resolve_log/client/request). `loads_drain()` answers the head (READ, hot, or empty) when a lease is free via `load_finish()` (vsr_io_lease_alloc on `store_replica(store)`, a container_of over vsr_io_replica.store — the store must be embedded in a replica); `prepare_load()` issues one READ (LOAD slot kind, FIXED_FILE|FIXED_BUFFER, pool region, `load_range()` cuts the batch to a slab/segment); `load_done()` marks READ. `cold_active`/`cold_slab`: a fence keeps the slab until the CQE. Hot results pin [min ring offset, max end) under the lease index (`pin_range`).
- Base hold: `base_state` NONE/WANTED/LOADING/LOADED, `base_kind`, `base_op`, `base_id`, `base_sequence`, `base_slot`. `base_hold()` in store_pack scans the in-memory transaction (role = its HARD_STATE's if present, else hard.role). `base_apply(id, sequence, source)` sets base_offset from capture_offset or next_offset, sweeps for RESTORE, computes client_base.
- Freeing: `vsr_io_store_free_floor` (first live op from retained_begin, kept versions, reclaim, client_base+1, capture_floor); `vsr_io_store_free_segments` frees SEALED slots below the floor that are `segment_quiescent` (every extent below written_floor) and not `segment_loading`; dead extents get segment = NONE (extent_locate/issue_extent skip them); phase FREEING (FREE in memory-only mode); superblock_done converts FREEING -> FREE only when superblock_dirty == 0. `segment_free_slot` requires number 0 and phase FREE. store_pack: free, then grow, else wait while a slot is FREEING, else `store_abort` (pop + complete + store_fail; store_pack returns false).
- store_fail: queued loads complete FAILED (a READING one keeps its slab), base_state cleared. `store_abort` fixed a latent phase-1 double pop (store_fail drains the head STORE while store_pack's caller pops again).

## Invariants (in addition to phase 1's)
- Sequences never decrease along the op ring; the ring holds exactly the ops of [retained_begin, log_end) that are current versions; a slot holds op X only when X is current.
- `client_base + 1` frees no record only the log holds: every entry with current.sequence <= client_base has base_offset set (base_apply lowers client_base otherwise).
- A freed slot's extents are dead before any reuse; a slot with a write in flight or a queued load is never freed; a FREEING slot is never opened.
- LOAD completions: OK always with a lease (pin or slab or neither for an empty result); RETRY/NOT_FOUND/CORRUPT/FAILED without.
